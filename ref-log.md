## External Tools and Libraries
- **Streamlit** – Frontend framework for building the interactive chat UI.  
- **LangChain** – Used for chunking, prompt templating, and RAG pipeline logic.  
- **ChromaDB** – Local vector store for embedding and retrieval.  
- **OpenAI (via Cornell API Gateway)** – Provides embeddings (`text-embedding-3-small`) and chat model (`gpt-4o`).  
- **pypdf** – Used for parsing PDF text content. 
- **Python Standard Libraries** – `os`, `environ`.
